Un setup « validé » signifie seulement que les cases obligatoires sont cochées. Cela ne signifie ni probabilité élevée ni rentabilité prouvée.

Référentiel de setups

A · Sweep + MSS + FVG

Sweep BSL/SSL → displacement → MSS confirmé par clôture → FVG → retest/réaction. Stop au-delà du sweep. Pas d'entrée sur le sweep seul.

B · Continuation

Structure HTF et BOS → retracement dans OB/FVG → réaction → reprise confirmée en LTF. Stop au-delà de l'invalidation structurelle.

C · SMT + confirmation

Divergence sur marchés comparables → sweep sur l'actif tradé → displacement → MSS → FVG. La SMT seule n'est jamais un déclencheur.
