# Session Desk — Trading Playbook

Tableau de bord web autonome pour préparer une session de trading.

## Utilisation
Ouvrir le site GitHub Pages. Les préparations et journaux sont conservés dans le stockage local du navigateur. Exporter régulièrement une sauvegarde JSON ; les données ne sont pas synchronisées entre appareils.

## Fonctions
- Checklist de préparation et décision avant session.
- Contexte multi-timeframe, macro et niveaux de liquidité.
- Fiches de setups SMC.
- Calculateur de risque et de lots.
- Journal, revue post-session, export JSON et impression PDF.

Les données de marché ne sont pas chargées automatiquement. Vérifier les spécifications réelles du symbole dans MT5 ; les valeurs préremplies du calculateur sont illustratives. Cet outil ne constitue pas un conseil financier.


## Publication
GitHub Pages est configuré avec le workflow automatique `.github/workflows/pages.yml`.
